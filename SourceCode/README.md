# Current WordCrafter Pro 2.0 Source

This directory contains the current PySide6 / Qt6 source tree used to build Release v2.0.

- core/ — persistence, sessions, decks, SRS, logs, dictionary store
- services/ — AI streaming, dictionaries, pronunciation, translation, updater
- qt/ — desktop shell, pages, renderer, typography and widgets
- theme/ — palettes, tokens and presets
- webui.py — token-protected local Web UI
- assets/ — Neko application icon and Web UI assets
- tests/ — core, Qt offscreen and Web end-to-end tests

The complete source archive is WordCrafterPro_v2.0_Source_NekoIcon.zip in this folder and in Release v2.0.
